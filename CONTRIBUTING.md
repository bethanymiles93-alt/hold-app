# Contributing

## Before changing a core journey

Read:

- `docs/01-mvp-scope.md`
- `docs/03-privacy-model.md`
- `docs/04-content-rules.md`

## Pull-request expectations

Describe:

- the user problem
- the low-capacity implication
- privacy impact
- accessibility impact
- screenshots or recordings
- tests performed

## Non-negotiables

Do not:

- add automatic sending
- log message content
- upload contacts by default
- introduce guilt copy
- add engagement mechanics
- call a model provider directly from the mobile client

# Content rules

## Voice

- warm
- direct
- adult
- non-clinical
- emotionally precise
- non-demanding

## Prohibited language

- “You disappeared”
- “People are waiting”
- “You’re overdue”
- “Get back on track”
- “You should”
- “Just reply”
- fake urgency
- false promises about another person's response

## Draft anatomy

A draft may contain:

1. current state
2. reassurance about the relationship
3. boundary
4. expectation
5. return signal

Not every message needs every part.

## Completion language

### Create a Hold

> Ready.  
> Then rest.

This is deliberately more accurate than “Sent” because the native share sheet may not confirm final delivery.

### Return

> That was enough.  
> Come back gently.

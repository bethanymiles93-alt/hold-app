# User-testing plan

## Round 1: comprehension

Test with 5–7 participants.

Observe:

- whether “Create a Hold” is understood
- whether users distinguish Hold from therapy or crisis support
- whether the native share step is clear
- whether message drafts feel natural
- whether completion wording is truthful

## Round 2: low-capacity simulation

Ask participants to complete the flow while:

- using a smaller screen
- increasing system text size
- being interrupted
- skipping optional explanation
- selecting only one person

Do not claim this recreates depression, fatigue or ADHD. It tests resilience under constrained attention.

## Round 3: recipient response

Show messages to recipient participants.

Ask:

- What do you think this person is telling you?
- What do you think they want from you?
- Would you feel reassured, worried, dismissed or confused?
- What would you do next?

## Core outcomes

- completion rate
- time to reviewed draft
- number of edits
- perceived emotional effort
- perceived guilt reduction
- recipient understanding
- trust in privacy
- willingness to use in a real moment
